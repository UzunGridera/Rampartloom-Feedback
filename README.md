# Rampartloom Beta Feedback

This public tracker is the official place to share beta feedback and report
bugs for **Rampartloom: PvP Tower Defense**.

Choose **New issue**, then select one of the structured forms:

- **Beta feedback** — tell us what feels fun, confusing, slow, unfair, or
  worth improving.
- **Bug report** — report reproducible game problems with clear steps.

## Public-submission safety

Everything submitted here is public. Do not include:

- your real name, email address, Steam ID, account IDs, IP address or other
  personal data;
- passwords, authentication codes, access tokens or secret keys;
- game logs, support ZIPs, crash dumps, raw JSON reports or private files;
- screenshots that contain personal or account information.

The game opens this page only after you confirm. It does not upload files,
copy diagnostics, attach your player name, or submit a ticket automatically.
GitHub sign-in may be required to post.

Reports may be closed, edited, labeled or removed for safety and moderation.
Response times are not guaranteed during beta.

## Security reports

Do not disclose a security vulnerability in a public issue. Use this
repository's **Security → Report a vulnerability** route instead.
